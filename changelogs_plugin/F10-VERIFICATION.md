## Reproducibility

For VectHare, run each `tests/*.node.test.mjs` in its own Node VM-module process to avoid the pre-existing intermittent monolithic test-runner crash. Validate all `.js`/`.mjs` files with `node --check`. The plugin build manifest is generated by `node tools/s10-build-manifest.mjs` after modifying executable source.
